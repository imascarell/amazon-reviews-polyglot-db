# Data

Raw review files are **not** included (size and third-party license).

Download the 5-core review files from the Amazon product data collection (McAuley et al., UCSD):
<https://jmcauley.ucsd.edu/data/amazon/>

Place them in this folder with these names:

- `Toys_and_Games_5.json`
- `Video_Games_5.json`
- `Digital_Music_5.json`
- `Musical_Instruments_5.json`
- `Sports_and_Outdoors_5.json` (used by `inserta_dataset.py` to add a fifth category)
